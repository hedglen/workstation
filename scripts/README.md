# Workstation scripts

- `rio-doctor.ps1`: optional interactive Rio renderer troubleshooting. Preview-only by default; `-Apply` backs up and modifies Rio's local config and may stop running Rio processes.
- `health.ps1`: read-only checks for the curated manifest, WinGet, and configuration files.

No WSL, Scoop, Python virtual environments, OCR, or transcription setup is part of Workstation.
