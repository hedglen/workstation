# Workstation scripts

- `rio-doctor.ps1`: optional interactive Rio renderer troubleshooting. It modifies Rio's local config and terminates running Rio processes; review before use.
- `health.ps1`: read-only checks for the curated manifest, WinGet, and configuration files.

No WSL, Scoop, Python virtual environments, OCR, or transcription setup is part of Workstation 2.0.
